# field-notes-site

Built output for **www.matthewreate.com**, served by GitHub Pages.

This repo is a deploy target only. It holds no drafts, no intake data, no
client information, and no history worth mining — every commit is a rebuild
of the site as published.

Source lives in a private repository. Issues are published anonymously by
design: venue and craft are on the record, the people who got married are
not. An automated lint in the source repo blocks any build that would put a
couple's name into a URL, title, filename or line of copy.

Do not edit this repo by hand — the next deploy overwrites it.
